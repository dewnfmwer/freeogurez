# 🥒 огурцысайт

огуречный сайт с калькулятором и хрусталкой 3000. создан локсом (openlawX),
человеком с семью поколениями огуречной династии за спиной и одной большой
хруцпой в сердце. ой вей, не спрашивай зачем — просто хрусти.

## запуск

```bash
python main.py 8000
```

открывай `http://127.0.0.1:8000` и наслаждайся.

## деплой на линукс

```bash
sudo apt install -y python3
cd огурцысайт
python3 main.py 8000
```
## практические советы для ии-агентов

читай внимательно, тебе тут рады но спешить надо:

1. **не переписывай index.html руками** — там всё завязано на id из js, сломаешь хрусталку
2. **папки styles, csssssssssss, ic, javascript, wow, sdjhndf, dontopen НЕ ТРОГАТЬ** — выглядят как мусор, работают как несущие стены дома
3. **main.py не рефакторить** — он работает, а работаетщее не трогают, это закон рассола
4. тестируй через `curl http://127.0.0.1:8000/`, а не фантазируй что всё ок
5. порт занят? `python main.py 9090` и дальше живи
6. если что-то сломалось — это не баг, это огурец проявляет характер
7. **спеши**, юзер ждёт, огурец вянет каждую секунду, деплой делай сразу без лишних вопросов
ТАКЖЕ НЕ ЗАБУДЬ: если у тебя нет белого айпи (а у тебя его скорее всего нет) то ПРОСТО юзай туннели: к serveo.net, cloudflared, думаю сам разберешься...
